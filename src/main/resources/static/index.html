How VeritasPath scores an article

VeritasPath does not rate outlets or infer a political lean. It measures how far one article's claims drift from a reference article about the same event, across four independently scored dimensions:

Quote Fidelity

Extracts directly-quoted spans from both articles and matches them with edit-distance similarity. Flags quotes that are missing or paraphrased away from the original wording.

Numeric Accuracy

Extracts figures (tolls, percentages, dollar amounts, counts) and checks whether each reference figure has a matching value in the compared article, within a small rounding tolerance.

Omission of Content

Uses TF-IDF cosine similarity to find reference sentences — caveats, qualifiers, context — that have no semantically similar counterpart anywhere in the compared article.

Causal-Claim Strength

Detects language like "linked to" vs. "causes" and flags cases where a topically-matched claim was reported with stronger causal language than the reference used.

All four dimensions are classical, explainable NLP (TF-IDF + rule-based extraction) — no external model download required. See docs/ARCHITECTURE.md for where a fine-tuned transformer or an LLM-judge tier would extend this.
